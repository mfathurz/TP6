1. Jelaskan secara singkat apa itu JavaScript dan kegunaannya! [5 Poin]

Jawab : JavaScript Adalah bahasa pemrograman yang digunakan untuk membuat halaman WEB menjadi interaktif, misalnya untuk menampilkan pesan, merespon klik tombol, menerima input pengguna dan sebagainya

2. Jelaskan secara singkat apa itu jQuery dan kegunaannya! [5 Poin]

Jawab : JQuery itu seperti library dari javascript yang mempermudah penulisan kode untuk mengatur elemen HTML, menangani klik tombol, mengubah tampilan, dan membuat animasi pada halaman web

3. Jelaskan perbedaan JavaScript dan jQuery! [10 Poin]

Jawab :JavaScript merupakan bahasa pemrograman, sedangkan jQuery adalah library yang dibuat menggunakan JavaScript. JavaScript dapat digunakan langsung untuk membuat halaman web interaktif, sedangkan jQuery menyediakan fungsi-fungsi yang membuat penulisan kode menjadi lebih singkat dan praktis
